# Features & Modules

## Module 1: Data Import & School Setup
- 1-click Excel / CSV teacher–subject allocation import
- School bell & period setup (working days, periods/day, breaks, lunch)
- Classrooms, labs & shared space configuration

## Module 2: Smart K–12 & Kerala Constraint Engine
- Simultaneous language splits (Malayalam / Hindi / Arabic / Sanskrit)
- Plus Two & stream elective splits (Science, Commerce, Humanities)
- Consecutive double-period locking (Labs & PE)
- Heavy-subject placement rules (avoids Math/Science in post-lunch/last periods)
- Teacher consecutive-class cap (prevents burnout)

## Module 3: Clash-Free Master Timetable Generator
- Auto-generates 100% conflict-free master timetable in minutes
- Zero double-booking across teachers, classes & labs
- Quick manual drag/swap edits with instant clash warnings
- Class-wise, teacher-wise & lab-wise views

## Module 4: 7:30 AM Daily Proxy / Substitution Engine
- Mark absent teachers in seconds (full-day or period-wise)
- Auto-suggests & assigns available substitute teachers
- Smart ranking by subject/class familiarity
- Fair daily & weekly workload balancing
- Substitution history & load tracker

## Module 5: Instant Print & Export Module
- Print-ready PDFs for classroom doors & staffroom noticeboards
- Daily proxy sheet PDF ready for morning staffroom display
- Clean Excel exports (master timetables & substitution records)
